الإعدادات

اربط الأداة بحساب OpenAI الخاص فيك. المفتاح بيتخزن محلياً بمتصفحك بس، وما بينرسل لأي جهة غير OpenAI مباشرة.

اتصال OpenAI API

افتراضياً gpt-5.6-sol — أقوى موديل نصي عند OpenAI حالياً (صدر 9 يوليو 2026)، أفضل خيار لفهم دقيق للوصف الوظيفي وقاعدة بياناتك. بديل أرخص وشبه بنفس الجودة: gpt-5.6-terra. للاستخدام العالي الحجم فقط: gpt-5.6-luna.

إدارة البيانات المحلية

كل شي — المفتاح، قاعدة بياناتك، آخر CV ولّدته — محفوظ محلياً بمتصفحك (localStorage). ما في نسخة احتياطية تلقائية بمكان تاني.
